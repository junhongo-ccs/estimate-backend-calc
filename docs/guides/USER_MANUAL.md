# AI見積もりシステム - ユーザーマニュアル

**対象者**: 営業部門・非技術者  
**運用方式**: Dify 2アプリ構成  
**最終更新**: 2026-03-24

---

## このシステムについて

現在の AI見積もりシステムは、用途の異なる 2 つの Dify アプリを組み合わせて使います。

1. 見積作成アプリ
   - 案件条件を入力して、見積結果と説明を出します
   - 価格シミュレーターに渡す JSON も最後に出します
2. 価格シミュレーター
   - 見積作成アプリが出した JSON を貼り付けて、売価・利益額・利益率を試算します

この 2 段構成にすることで、

- 見積作成は説明重視
- 価格調整は会話重視

という役割分担ができます。

## 使い方の全体像

普段の使い方は次の順番です。

1. 見積作成アプリを開く
2. 案件条件を入力して見積結果を出す
3. 回答末尾の `価格シミュレーターコピペ用JSON` をコピーする
4. 価格シミュレーターを開く
5. コピーした JSON を貼って質問する

重要:

- 価格シミュレーターには、案件条件を最初から全部入れません
- 見積作成アプリが出した JSON を貼ることが前提です

## 1. 見積作成アプリの使い方

### 入力する主な項目

見積作成アプリでは、主に次のような項目を入力します。

- プロジェクト名
- 部門
- 見積プロファイル
- 目標利益率
- 対象プラットフォーム
- 開発種別
- 画面数
- テーブル数
- 追加機能
- 期間
- 確度
- Phase2 項目
- Phase3 項目

### 出力されるもの

見積作成アプリでは、次の 2 種類の情報が返ります。

1. 見積説明文
   - 案件サマリ
   - 積算根拠
   - 採算性評価
   - 営業向けコメント
2. 価格シミュレーターコピペ用JSON

例:

```json
{
  "project_name": "ユーザー案件",
  "cost": 42717253,
  "current_sales": 31668483,
  "target_margin": 0.1,
  "currency": "JPY"
}
```

### 注意

- `project_name` を入力しない場合、自動で `ユーザー案件` が入ります
- 価格シミュレーターへ進むときは、説明文ではなく JSON をコピーします

## 2. 価格シミュレーターの使い方

価格シミュレーターは、見積作成アプリが出力した JSON を貼って使います。

### 最初にやること

次のように、JSON と質問文を一緒に貼ります。

```text
以下のJSONを前提に、この案件の売価、営業利益額、営業利益率を教えて。

{
  "project_name": "ユーザー案件",
  "cost": 42717253,
  "current_sales": 31668483,
  "target_margin": 0.1,
  "currency": "JPY"
}
```

### できる質問

#### 1. 現在売価の確認

```text
以下のJSONを前提に、この案件の売価、営業利益額、営業利益率を教えて。
```

#### 2. 必要売価の確認

```text
以下のJSONを前提に、目標利益率を満たすための必要売価を教えて。
```

#### 3. 複数価格案の比較

```text
以下のJSONを前提に、45,000,000 円 / 47,500,000 円 / 50,000,000 円で比較して。
```

#### 4. 個別価格での再試算

```text
以下のJSONを前提に、売価を 48,000,000 円にした場合の営業利益額と営業利益率を教えて。
```

### 価格シミュレーターで分かること

- 現在売価での利益額
- 現在売価での利益率
- 赤字か黒字か
- 目標利益率を満たす必要売価
- 複数価格案の比較

## 注意事項

### 見積について

> [!IMPORTANT]
> - 出力は概算です
> - 正式見積は詳細要件確認後に実施してください
> - 採算性が大きく悪い場合は、価格だけでなくスコープや体制の見直しも必要です

### 入力データについて

> [!WARNING]
> - 個人情報や機密情報は入力しないでください
> - 案件名は社内で問題ない範囲に留めてください
> - 価格シミュレーターには、見積作成アプリが出した JSON を使ってください

### 役割分担について

- 見積作成アプリ:
  - 案件条件の入力
  - 見積金額の算出
  - 見積根拠の説明
- 価格シミュレーター:
  - 売価の再試算
  - 利益額・利益率の確認
  - 価格比較

## トラブルシューティング

### 価格シミュレーターで何を入れればいいか分からない

対処法:

1. 見積作成アプリに戻る
2. 回答末尾の `価格シミュレーターコピペ用JSON` を探す
3. その JSON をコピーして貼る

### JSON を貼ったのに意図した結果にならない

対処法:

1. JSON 全体を貼れているか確認
2. `}` まで含めてコピーできているか確認
3. 質問文と JSON を一緒に貼る

### 後から案件名を変えたい

対処法:

1. 見積作成アプリに戻る
2. `プロジェクト名` を入力または修正する
3. 新しい JSON を出し直す

### 画面がうまく表示されない

対処法:

1. ページを再読み込みする
2. 別ブラウザで試す
3. キャッシュをクリアする

### 応答に時間がかかる

対処法:

1. 数秒から十数秒ほど待つ
2. 反応がない場合は再読み込みして再試行する

## よくある質問

### Q. 価格シミュレーターだけ使えばよいですか？

A. いいえ。価格シミュレーターは見積作成アプリが出した JSON を受け取って使う想定です。最初に見積作成アプリを使ってください。

### Q. `project_name` を入れなくてもよいですか？

A. はい。未入力の場合は `ユーザー案件` として扱われます。

### Q. 価格シミュレーターに案件条件を最初から全部書く必要はありますか？

A. ありません。見積作成アプリが出した JSON を貼れば十分です。

### Q. 利益率がマイナスの場合は何を意味しますか？

A. 現在の売価では赤字であることを意味します。必要売価を確認し、価格交渉またはスコープ調整を検討してください。

## まとめ

このシステムは、次の 2 ステップで使うのが基本です。

1. 見積作成アプリで見積と説明を出す
2. 価格シミュレーターで売価を再試算する

最も重要なのは、見積作成アプリの最後に出る `価格シミュレーターコピペ用JSON` を使うことです。

これにより、見積作成から価格交渉シミュレーションまでを、会話形式で連続して実施できます。
